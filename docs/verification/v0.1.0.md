# v0.1.0 validation / 验证范围

The core requirements are implemented: text and static-image clipboard history, image preview/restore/PNG export, favorites, reusable snippets with JSON import/export, text cleanup, tray and hotkey, recording controls, local data location settings, current-user DPAPI encryption and installation/uninstallation.

基本需求已实现：文字和静态图片剪贴板历史、图片预览/恢复/另存 PNG、收藏、常用语 JSON 导入导出、文本清洗、托盘与热键、记录控制、本地数据位置设置、当前用户 DPAPI 加密和安装/卸载。

本地自包含包通过 491 个载荷文件散列校验、运行时许可、隔离安装与自卸载、未知文件保留、自带运行时加载、WPF 暂停状态、SQLite 创建和等价数据路径的单实例验证。仓库尚未发布预编译下载包。

Recording defaults to disabled. A new data profile requires explicit consent. Changing location preserves the old profile and exits after saving; data is not automatically moved or merged. A failed settings transaction restores the previous settings, location preference and startup registration. Explicit `--data-dir` takes priority and disables location editing.

记录默认关闭；新数据配置需主动授权。切换位置保留旧目录并在保存后退出，不自动搬迁或合并；提交失败恢复设置、位置指针和登录启动项。显式 `--data-dir` 优先且禁止在设置中修改位置。

Release builds omit debugging symbols. Packaging rejects common data/key/debug files and scans the current workspace and user-directory byte patterns in the expanded payload and final outputs. These bounded checks do not guarantee detection of all secrets or paths.

## Remaining acceptance / 仍需验收

- A clean Windows 11 x64 system without the SDK: default installation, first use, Start menu/Installed apps, exit/restart, login startup and uninstall.
- Real Notepad, browser, Office and image-editor workflows: text/image paste, focus, permissions and format support.
- Chinese IME confirmation, real multiple displays, 100%/150%/200% system DPI and display changes.
- Application cold startup and hotkey activation timings on the reference device.
- Manual use of the recording and data-location settings in the published source version.

无 SDK 干净系统、真实目标应用、中文输入法、多屏/系统 DPI、参考设备启动与唤起耗时，以及设置人工试用仍需逐项执行。默认测试通过不等于上述兼容性验收通过。

The optional `scripts/test.ps1 -IncludeDesktop` scenario has not passed locally because Windows rejected the initial foreground switch. Do not treat the default suites as proof of that optional scenario. See the [manual acceptance checklist](v0.1.0-manual.md); use synthetic content and an isolated data directory for destructive cases.

可选桌面场景因系统拒绝初始前台切换尚未通过。按[人工清单](v0.1.0-manual.md)记录通过、失败或未测；删除、损坏等场景只用合成内容和独立测试目录。
