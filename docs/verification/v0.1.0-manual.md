# v0.1.0 外部环境验收清单

用合成文字和图片执行以下步骤，把系统版本、应用版本、显示设置和实际结果记入验证记录。不要提交个人剪贴板、办公截图或数据库。

清空、删除、错误配置和损坏恢复场景只在独立测试数据目录中执行；保留日常使用目录及其备份。可用显式 `--data-dir` 打开测试目录，避免清理个人历史。

## 当前电脑先试用

1. 从项目 `artifacts/releases` 取最终安装器或 ZIP，并用同目录 `SHA256SUMS.txt` 核对。若此前已安装同名版本，先明确保留数据并卸载，或将 ZIP 解压到单独目录；安装器不会覆盖现有安装目录。
2. 首次启动选择“暂不开启记录”。复制合成文字和一张只含合成内容的静态图，确认历史不增加；随后主动开启记录并重新复制，确认能搜索文字、预览图片、恢复图片到系统剪贴板和另存 PNG。
3. 只在空白文档或测试输入框中试“粘贴到原窗口”。先试记事本，再试浏览器、可用的 Office 和图片编辑器；失败时记录应用名、操作顺序与是否出现手动粘贴提示，不提交真实文字或截图。
4. 用中文输入法搜索并确认候选词，测试关闭回托盘、明确退出后重启，以及本机实际具有的显示器和缩放配置。没有的 Office、第二显示器或缩放环境记为未测，不推断通过。
5. 用一条记录写下每个场景“通过 / 失败 / 未测”及简短现象。无 SDK 的干净系统验收仍需另一台机器或独立虚拟机。

## 干净 Windows 11 x64

1. 使用没有 .NET SDK 的干净系统，核对安装器 SHA256，按当前用户安装。
2. 首次打开选择暂不开启。先复制合成文字和截图，确认历史为空；主动开启后，新复制内容进入历史。
3. 保存一条文字、一张带透明区域的图片、一个收藏和一个常用语；明确从托盘退出，重新打开确认仍在。
4. 开启登录启动，注销后登录；确认记录状态、内容和自定义数据目录与设置一致。关闭登录启动后再确认。
5. 从 Windows“已安装的应用”卸载，分别验证保留数据与明确删除默认数据。自定义目录和用户自建文件应保留。

## 真实目标应用与图片

| 场景 | 操作与预期 |
| --- | --- |
| 记事本 | 输入框获得焦点后 Ctrl+Alt+V 唤起；选择合成历史文字“粘贴到原窗口”，应进入原输入位置 |
| 浏览器输入框 | 在测试页面的普通 textarea 内重复文字流程；焦点无法恢复时显示手动粘贴提示 |
| 可用的 Office | 在 Word 或 Excel 编辑位置验证 Unicode 文字；另在支持图片的位置验证图片粘贴，记录具体应用版本 |
| 图片编辑器 | 在支持像素/透明度的编辑器粘贴历史图；核对宽高、颜色与透明区域。不能以目标应用不支持透明度判定 PNG 数据丢失 |
| 截图工具 | 连续截图至少三次，按图片类型、时间和收藏找回，再退出/重启恢复 |
| 另存 PNG | 另存后在独立查看器打开；同名文件须确认覆盖，不可写位置须提示；历史内容不变 |
| 降级 | 唤起后关闭目标窗口，再选择粘贴；应保持剪贴板并提示手动使用，不向其他窗口输入 |

## 中文输入法与显示环境

1. 用中文输入法在历史搜索输入关键词，按 Enter 确认候选词，应继续搜索且不触发自动粘贴。
2. 分别在真实 100%、150%、200% 系统缩放下打开所有页面、设置、常用语编辑与完整图预览；文字可读，按钮可见，可滚动到所有设置。
3. 在两台显示器之间唤起/移动面板，检查不同缩放、负坐标、屏幕拔插与工作区边缘；窗口应可找回。
4. 按住 Ctrl/Alt 唤起并选择粘贴，释放后再输入；应等待释放或回退，不发送混合按键。
5. 切换系统浅色/深色，确认搜索、选中标签、预览和对话框可读。

## 设置中的记录与数据位置

1. 从设置页暂停或开启记录，保存后确认主面板和托盘状态一致；暂停期间不新增历史，重启后状态保持。
2. 先在当前目录保存合成历史和常用语，再选择一个新的空测试目录。确认提示旧内容不会自动搬迁或合并；保存后应用应退出，正常重新打开后使用新目录。
3. 新空目录首次使用应说明保存范围并等待主动开启记录；旧历史与常用语留在原目录。再从设置选择带有效工具箱标识的原目录，保存退出并重开，确认原内容仍在。
4. 选择含其他文件且无工具箱标识的目录、文件路径或不可写位置，保存应报错且保留原目录和设置，不退出应用。取消对话框不得修改目录指针。
5. 使用显式 `--data-dir` 启动时，数据位置选择应禁用并说明原因；此参数优先于设置中保存的位置。
6. 若开启了登录启动，切换目录后注销再登录，确认使用新目录；原目录的数据库和自建文件不被删除。此项未实际注销登录时记为未测。

## 记录控制与恢复

1. 设置一个可确定来源的测试应用为排除应用，从中复制合成文字与图片，应不记录。
2. 暂停记录后复制，历史数量不增；已有文字、图片和模板仍可使用。
3. 清空未收藏历史，确认收藏和独立模板仍保留；删除全部内容二次确认后删除全部并暂停。
4. 仅对独立测试数据目录模拟错误设置、损坏数据库或错误账户打开，应报错并保留原文件。先备份，勿改正常使用的数据库。

这份清单是待执行步骤，不代表上述外部环境已通过。
