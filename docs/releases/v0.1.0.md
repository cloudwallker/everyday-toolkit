# v0.1.0 — 本地交付说明 / Local delivery notes

日用工具箱首版提供文字与静态图片剪贴板历史、收藏、可编辑常用语和文本清洗，以中文快捷面板、托盘和可配置热键连接复制、找回、整理与再次使用。目标平台为 Windows 11 x64，核心功能离线运行，内容通过当前 Windows 用户 DPAPI 加密保存。

Everyday Toolkit provides text/static-image clipboard history, favorites, editable snippets and text cleanup through a Chinese quick panel, tray and configurable hotkey. It targets Windows 11 x64, works offline and encrypts content with current-user DPAPI.

这是本地交付记录，尚未创建公开 GitHub Release。最终测试与资产验证仍按实际运行结果记录；不以源码就绪或文件生成推断所有场景通过。完整命令、测试数量、性能/容量数字、包体和校验结果以[验证报告](../verification/v0.1.0.md)为准。

## 功能

- 剪贴板：文字搜索、类型/时间/收藏筛选、内容去重、图片缩略图与完整预览、复制、尝试粘贴到原窗口、另存 PNG。仅复制文件列表不会读取文件。
- 常用语：名称/分类/正文搜索、新建/编辑/删除、历史文字转独立模板、复制/粘贴、JSON 导入/导出。
- 文本清洗：去首尾空白、去空行、行去重、直接/空格合并断行、ASCII 全半角转换，原文与可编辑结果对照。
- 记录默认关闭，首次使用由用户选择开启；面板、托盘和设置均可暂停/恢复，并可按应用排除。设置支持选择本机空或有效标识的数据目录；保存切换后退出，原内容和设置保留，不自动搬迁，新空目录重新确认记录授权。开机启动由用户主动设置，关闭面板回托盘，托盘退出才结束应用。
- 历史默认 1,000 条/200 MiB 加密载荷，未收藏最近使用后 7 天过期；收藏计配额并免自动删除。常用语独立 1,000 条/10 MiB。超限拒绝新增，不静默截断或缩小原图。

## 本地资产与安装

最终交付文件放在 `artifacts/releases`；仅在对应验证记录确认后作为可分发资产。`artifacts/snapshots` 保存历史构建，不能代替最终发行包或用于分发。

| 文件 | 用途 |
| --- | --- |
| `EverydayToolkit-0.1.0-Setup.exe` | 当前用户安装，嵌入完整 Windows x64 自包含载荷，附独立卸载器 |
| `EverydayToolkit-0.1.0-win-x64.zip` | 完整目录版，解压后运行 `EverydayToolkit.App.exe` |
| `SHA256SUMS.txt` | 本次安装器与 ZIP 的实际 SHA256 |

安装版默认 `%LOCALAPPDATA%\Programs\EverydayToolkit`，注册 HKCU 卸载信息与当前用户开始菜单入口；无需管理员权限或另装 .NET。目录版不注册系统安装入口。两者默认数据位于 `%LOCALAPPDATA%\EverydayToolkit`，设置可保存下一次普通启动的数据位置指针。显式 `--data-dir` 参数优先且设置页位置只读。登录启动作为用户全局选项从实际注册状态读取，普通模式跟随指针，显式模式保留该参数；保存失败会恢复原注册值及类型。

升级先退出应用、备份数据、卸载旧安装并选择保留数据，再安装新版。安装器拒绝覆盖已有目录；卸载只删除有效清单中的文件，未知文件保留。默认数据删除需要有效应用标识，用户明确选择后仅删除已知数据库/日志/设置文件，自选数据目录手动管理。辅助卸载 exe 可能留在 Windows Temp 供系统清理。

自有代码使用 MIT。发行包依据实际解析的运行包标识/版本保存原始许可、第三方声明与来源清单，见 [THIRD-PARTY-NOTICES](../../THIRD-PARTY-NOTICES.md)。安装器尚未数字签名，系统可能显示发布者未知。

## 验证入口和已知限制

默认 `scripts/test.ps1` 包含四套行为控制台、App `--settings-ui` / `--ui`、真实安装器进程场景及六项发行隐私扫描回归，串行执行。设置回归覆盖记录保存、目录指针与失败恢复、显式参数、原目录留存和删除期间的记录状态；UI 测试保留真实资源并抑制个人目录启动。`-IncludeDesktop` 额外运行跨进程合成接收窗口；本机该场景因系统拒绝前台窗口切换尚未通过，不能宣称真实外部应用自动粘贴已验收。

App 测试的 `--perf` 单独测量合成负载。`scripts/verify-package.ps1` 校验实际包散列、完整载荷安装/卸载及运行许可来源；`scripts/smoke-release.ps1` 检验实际自包含应用初始化与等价目录的单实例行为。每项实际结果见验证报告，生成资产本身不代表这些检查通过。

以下外部条件仍需按照[人工验收清单](../verification/v0.1.0-manual.md)独立验证：

- 无开发工具、无 SDK 的干净 Windows 11 x64 安装、首次使用、退出、重启及卸载；本机隔离运行时烟测不能替代它。
- 真实记事本、浏览器、Office 与图片编辑器的文字/图片粘贴、焦点恢复和权限回退；合成接收窗口不替代真实应用。
- 中文输入法确认、真实多显示器与 100%/150%/200% 系统缩放；离屏渲染不替代这些条件。

自动粘贴依赖原目标窗口可确认且支持目标格式；失败时保留剪贴板并提示手动粘贴。Enter 不触发自动粘贴。OCR、动画历史、云同步和 AI 改写不在首版范围。DPAPI 数据库不承诺跨机器/账户迁移；常用语 JSON 和另存 PNG 为用户主动生成的明文文件。

Clean-machine installation and real external application, IME, display and DPI acceptance remain separate. Historical snapshots must not be distributed.
