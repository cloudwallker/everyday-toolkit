# 日用工具箱使用说明

## 第一次启动

运行安装器或解压目录版，打开 `EverydayToolkit.App.exe`。第一次启动说明记录范围，默认关闭记录；主动选择开启后，只保存之后收到的新复制事件，不追溯启动前的剪贴板内容。开机启动默认关闭，在设置中主动开启。

默认 `Ctrl+Alt+V` 打开面板并聚焦搜索。快捷键冲突时显示提示，请在设置中改键或使用托盘。关闭面板回到托盘；从托盘选择退出才停止记录和释放热键。按 Enter 确认中文输入法候选词不会触发自动粘贴。

## 找回文字与图片

1. 开启记录，复制几段文字，或从截图工具/网页复制静态图片。
2. 打开剪贴板页，输入关键词找文字，或用类型、时间、仅收藏筛选找图片。
3. 选择条目，右侧查看文字或图像。图片可以打开完整预览；列表缩略图不等于缩小存储的原图。
4. 点击“复制”更新系统剪贴板，然后手动粘贴；也可点击“粘贴到原窗口”。图片能否贴入目标由目标应用支持的格式决定。
5. 收藏固定一条历史。“清空未收藏历史”保留收藏和常用语；单独删除收藏请使用条目的删除操作。

静态图片统一保存 PNG，包含像素尺寸与透明度；同一内容重复复制更新最近使用时间，不重复累积。仅复制图片文件路径/文件列表不会读取图片文件，GIF 动画和 SVG 对象不作为原始格式保存，不支持 OCR。文字搜索不搜索图片里的字。

“另存 PNG”由你明确选择目标位置，并告知输出是明文图像；已有文件需确认覆盖。导出不会修改历史。失败时检查目录权限或换路径，原历史会保留。

自动粘贴会等待 Ctrl/Alt/Shift/Win 释放，并确认原目标窗口仍存在、焦点仍正确后发送 Ctrl+V；等待超时、目标关闭、焦点不确定或权限受限时只保留剪贴板，提示手动粘贴。请使用页面按钮触发粘贴。

## 常用语与文本清洗

常用语页可以新建、命名、分类、编辑和按名称/分类/正文搜索，也可从历史文字选择“保存常用语”。这是独立副本，之后删除历史不会删除模板。图片不能保存为文字模板。

清洗页可以载入剪贴板文字、历史或常用语，也可直接输入。左侧原文，右侧可继续编辑的结果。规则包括去首尾空白、去空行、行去重、直接合并断行、空格合并断行，以及仅转换 ASCII 可打印字符和空格的全/半角转换。行去重保留首条顺序，断行统一为 `\n`。对照结果后选择复制、粘贴或保存常用语；原历史不会原地改写，常用语只有明确保存才更新。

## 记录控制、配额和恢复

随时在面板、托盘或设置的“记录新复制的内容”中暂停/恢复记录。设置中保存成功后记录状态立即生效；保存失败保留原状态。暂停仍能访问已有内容；退出会释放内存缓存。删除全部内容期间不能保存设置，完成后继续暂停，除非你主动重新勾选记录。设置中可按来源进程名排除应用（不区分大小写，可带 `.exe`），记录器尊重 Windows 敏感标记。来源不确定时不能保证识别所有敏感内容，请主动暂停。

| 范围 | 默认值和行为 |
| --- | --- |
| 历史 | 1,000 条；加密载荷 200 MiB；未收藏最近使用后 7 天过期 |
| 收藏 | 免自动过期但计共同配额；只剩收藏且配额满时阻止新增 |
| 单条文字 | UTF-8 256 KiB；超限跳过，不截断 |
| 单张图片 | PNG 8 MiB；解码像素内存 64 MiB；超限跳过，不静默缩小 |
| 常用语 | 独立 1,000 条/10 MiB；历史清理不影响 |
| 图像缓存 | 缩略图最多 100 张/16 MiB；完整图片最多一张/64 MiB |

历史容量按加密后正文和缩略图计量；数据库索引/日志另有磁盘开销，界面统计不代表磁盘绝对上限。收藏满时先清理不需要的收藏或调配额，再继续新增。

数据库或解密失败不会自动删库重建。退出应用，保留 `content.db`、可能存在的 `content.db-wal`/`content.db-shm` 和设置，再检查同用户权限、路径与备份。不要以“修复”为由覆盖唯一数据副本。报告错误类别和合成复现步骤，不上传个人数据库。

## 数据位置与迁移

默认数据和设置位于 `%LOCALAPPDATA%\EverydayToolkit`，安装目录位于 `%LOCALAPPDATA%\Programs\EverydayToolkit`；目录版也使用默认数据目录。内容使用当前用户 DPAPI 加密，元数据保留必要的类型、尺寸、时间、收藏、计量和内容哈希。设置及默认目录指针不保存正文。

在设置的“本地数据位置”中输入完整路径或点击“选择数据目录”，选择本机空目录或带有效工具箱标识的既有目录。无标识的非空目录、磁盘根目录、网络共享及不可写位置会拒绝切换。保存成功后应用立即退出；重新打开才使用新位置。原目录的文字、图片及设置保留，不自动搬迁或合并；新空目录需重新选择是否开启记录，既有目录使用自己的内容及设置。切回原目录可以继续使用其中的数据。切换失败时会尝试恢复原设置、默认目录指针、热键及登录启动注册；若恢复受权限或占用阻止，界面会提示检查。

默认目录中的 `settings.json` 保存下次普通启动使用的位置指针。显式运行 `EverydayToolkit.App.exe --data-dir "D:\ToolkitData"` 优先于该指针，设置位置控件只读；退出并修改启动命令才会更换这次实例的位置，普通记录开关不会改写已有指针。登录启动是当前 Windows 用户的全局选项：普通启动模式跟随位置指针，显式参数模式保留该目录参数。开启后实际注销/登录的效果需人工核对。

需要备份时先退出应用，再保存所需目录的数据库、日志和设置；同 Windows 用户权限的其他程序仍可能读到内容，DPAPI 不代替敏感内容排除。

跨机器/账户迁移常用语：旧机器常用语页“导出 JSON” → 将明文文件安全转移 → 新机器“导入 JSON”。格式如下，仅为合成示例：

```json
{
  "version": 1,
  "snippets": [
    { "name": "示例回复", "category": "示例", "text": "这是合成模板。" }
  ]
}
```

导入最多 16 MiB，先验证再事务写入；重名自动加 ` (2)` 等后缀。格式无效或总配额不足时整批失败，已有常用语不被部分改写。导出的 JSON 和 PNG 都是明文，请自行管理。加密数据库备份仅供同机器/同用户恢复，不承诺跨账户解密。

## 安装、升级与卸载

安装器只为当前用户安装，注册 HKCU 卸载信息和开始菜单入口，不要求管理员、不主动设置开机启动。目录版不注册这些信息。升级前先从托盘退出应用并备份；安装器拒绝覆盖已有目录，先卸载保留数据，再安装新版。不同版本的数据格式需遵循该版本说明。

卸载程序提供三种选择：是＝删除默认历史/收藏/常用语/设置，否＝保留数据，取消＝停止卸载。只删除标识为 `EverydayToolkit-v1` 的已知数据文件：`content.db`、`content.db-wal`、`content.db-shm`、`settings.json`、`toolkit-data.marker`。未知文件/目录保留，自定义数据目录请手动管理。卸载只删除 SHA256 安装清单列出的文件，清单非法或文件被修改时停止，不对任意目录递归删除。

卸载自己的 exe 时会复制一个小型辅助卸载器到 Windows 临时目录，等待原进程退出后删除安装清单文件。辅助 exe 可能留在临时目录，可通过系统临时文件清理删除；其中没有用户内容。操作失败会保留数据，请退出正在运行的应用并检查文件占用。

## 开发者受控验证模式

以下模式仅供项目根目录下 `artifacts` 合成数据验证，不代表支持静默安装到任意路径。必须配合 `--no-registration`，不会写真实卸载项、开始菜单或启动项：

```powershell
.\artifacts\releases\EverydayToolkit-0.1.0-Setup.exe --quiet --no-registration --install-dir "完整的项目路径\artifacts\install-check"
.\artifacts\install-check\Uninstall.exe --quiet --no-registration --uninstall-dir "完整的项目路径\artifacts\install-check"
```

删除合成数据还须显式提供位于 artifacts 的 `--data-dir` 和 `--delete-data`，并创建有效应用数据标识。缺失这些条件会拒绝删除，以防误操作真实默认数据。成功退出码 0，取消 2，错误 1；自删除助手异步启动，验证时需等待目标文件移除。真实注册行为在隔离的 HKCU 测试键中测试，不使用用户实际启动项。
